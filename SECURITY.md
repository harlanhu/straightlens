# Security policy

StraightLens is designed to run on the local machine and does not send uploaded images to a third-party service by default.

Please do not report sensitive information in a public issue. For a security concern, contact the repository owner privately through GitHub and include reproduction steps, affected files, and the impact.

The application accepts image uploads and writes temporary task files. Keep the service bound to a trusted interface unless you have added authentication and access controls for your deployment.
